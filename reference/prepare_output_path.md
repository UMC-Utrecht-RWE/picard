# Validate and prepare output path for saving

Validate and prepare output path for saving

## Usage

``` r
prepare_output_path(file_path, file_name = NULL, create_dir = TRUE)
```

## Arguments

- file_path:

  Path to save the file

- file_name:

  Optional filename to append

- create_dir:

  Whether to create directory if missing (default TRUE)

## Value

Named list with normalized_path
