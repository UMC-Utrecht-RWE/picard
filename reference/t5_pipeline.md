# T5Pipeline Class

This class is responsible for managing the T5 pipeline, including
loading configuration files, executing steps, and cleaning up files.

## Details

The T5Pipeline class is designed to handle the T5 pipeline for semantic
harmonization. It loads configuration files, executes the steps defined
in the configuration, and cleans up files as needed.

### `T5Pipeline$new()`

Initialize the T5 pipeline with a YAML configuration file.

#### Usage

    T5Pipeline$new(config_t5 = base::file.path("configuration", "config_T5.yaml"))

#### Arguments

- `config_t5`:

  Path to the YAML configuration file for T5

#### Returns

An instance of T5Pipeline
