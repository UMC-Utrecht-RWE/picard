# Read data from file based on extension

Read data from file based on extension

## Usage

``` r
load(file_path, file_name = NULL, col_types = NULL, ...)
```

## Arguments

- file_path:

  Path to the file

- file_name:

  Optional if not in file_path. Default NULL

- col_types:

  Optional, define the column type in output per column. It requires a
  list.

- ...:

  Additional arguments passed to the reader function

## Value

Data data.table
