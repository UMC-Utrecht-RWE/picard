# Compute file hashes

Compute file hashes

## Usage

``` r
get_hash_output(output_file = NULL, log_dir = "logs")
```

## Arguments

- output_file:

  Character or NULL. If NULL, a default file name is generated in the
  specified log directory.

- log_dir:

  Character. Directory to store the registry when created.

## Value

Character vector of hashes
