# Deprecated wrapper for load()

Deprecated wrapper for load()

## Usage

``` r
read_data(file_path, file_name = NULL, col_types = NULL, ...)
```

## Arguments

- file_path:

  Path to the file

- file_name:

  Optional if not in file_path. Default NULL

- col_types:

  Optional, define the column type in output per column

- ...:

  Extra args passed to the specific writer
